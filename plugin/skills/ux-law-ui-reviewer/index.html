02다섯 가지 법칙

Hick's Law

힉의 법칙

선택지가 많을수록 판단이 느려진다.

주요 행동과 보조 행동이 구분되는가

Fitts's Law

피츠의 법칙

멀고 작은 목표일수록 누르기 어렵다.

위험한 버튼이 주 버튼에 붙어 있지 않은가

Jakob's Law

제이콥의 법칙

사용자는 익숙한 방식대로 쓰려 한다.

관습대로 행동했을 때 실패하지 않는가

Law of Proximity

근접성의 법칙

가까운 것은 관련 있다고 본다.

섹션 간 간격이 섹션 내부보다 큰가

Von Restorff Effect

폰 레스토프 효과

다른 하나가 가장 눈에 띈다.

강조가 핵심 행동 하나에 모여 있는가

03사용법

  1. 스킬 설치: 폴더째 ~/.claude/skills/(Claude Code) 또는 ~/.codex/skills/(Codex)에 둡니다.
  2. 검토 요청: 스크린샷, 코드, URL, 화면 설명 중 하나와 함께 요청합니다.
  3. 결과 확인: ux-reviews/날짜_화면이름.html이 저장되고 ux-reviews/index.html에 한 줄이 추가됩니다. 이전 리뷰는 덮어쓰지 않습니다.
  4. 수정 후 재검토: 같은 화면을 다시 맡기면 이전 리뷰와 비교해 해결된 문제와 남은 문제를 적습니다.
이 화면 UX 관점에서 검토해줘 화면이 왜 복잡한지 분석해줘 버튼·메뉴 배치 개선해줘 게임 HUD 가독성 봐줘 모바일 터치 동선 확인해줘 이 React 컴포넌트 UX 리뷰해줘
