# 예시 입력: 모바일 액션 RPG 전투 HUD (화면 설명)

게임 HUD 가독성이랑 조작성 좀 봐줘. 모바일 액션 RPG야.

- 좌상단에 체력바(빨강)·마나바(파랑)·경험치바(노랑)가 각각 얇게 3줄
- 우상단 미니맵 옆에 퀘스트 목록 5줄이 항상 펼쳐져 있음
- 하단 중앙에 스킬 버튼 6개가 가로 한 줄(각 40px 정도)
- 오른쪽 아래 공격 버튼, 공격 버튼 바로 위에 '마을 귀환' 버튼이 같은 크기로 있음
- 화면 가운데 위쪽에 이벤트 배너가 반짝이며 계속 떠 있음
- 보스 공격 예고는 바닥에 얇은 빨간 원으로만 표시됨
- 왼쪽 아래 가상 조이스틱
